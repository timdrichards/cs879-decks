Keeping your journal safe

Your journal is saved in this browser automatically. Browser storage can be cleared without warning, so link a file as well: the journal is then written to a real file on your disk every time it changes, and you can keep that file in Dropbox, iCloud, OneDrive or a git repository and have it follow you between machines. If your browser does not support linking, download the JSON each week instead and import it if you ever lose the browser copy.
